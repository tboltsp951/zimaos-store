# Tbolt Apps — a ZimaOS app store source

Self-hosted, local-first apps by tbolt. Every app stores its data on your NAS at `/DATA/AppData/<app>/`, so it survives container rebuilds and is shared across every browser on your network.

## Add this store to ZimaOS

**App Store → Add source** and paste:

```
https://tboltsp951.github.io/zimaos-store/store.json
```

Behind the scenes ZimaOS calls `POST /v3/app_store/repo {"url":"..."}`. Updates are pushed to the gh-pages branch on every commit to `main`, so the store stays current with no extra steps.

## Adding or updating an app

1. Add/edit `Apps/<Name>/docker-compose.yml` (with its `x-casaos` metadata) plus `icon.svg`, `thumbnail.svg`, and a screenshot asset.
2. Commit and push to `main`.
3. The `Build and Publish Store` workflow rebuilds `dist/` and deploys it to `gh-pages`. ZimaOS picks the change up on its next store sync.
